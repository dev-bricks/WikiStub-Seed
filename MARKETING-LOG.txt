2. TARGET PERSONAS & USER JOURNEYS
================================================================================
1. AI & LLM Engineers (RAG & Local Knowledge Injection)
   - Needs: Inject high-signal, domain-curated knowledge stubs into local LLM contexts, vector stores (FAISS, Chroma, Qdrant), or agent prompts without scraping latency or noisy web HTML.
   - Pain Points: Raw Wikipedia dumps (XML/Wikitext) are multi-gigabyte beasts packed with parsing noise, navigation boilerplate, and inconsistent schemas.
   - WikiStub-Seed Solution: Compact, deterministic `wikistub_seed.json` (630 stubs) with structured definitions and relevance notes across 6 languages ready for direct JSON or Markdown ingestion (`wikistub_seed_pipeline.py export`).

2. Domain Researchers, Curators & Ontologists
   - Needs: Maintain a clean, cross-disciplinary concept hierarchy spanning 12 academic fields (Math, Physics, Chemistry, Biology, Medicine, CS/AI, etc.) with verified terminology.
   - Pain Points: Complex ontology tools (Protégé, OWL, RDF stores) require specialized knowledge and heavy setups, making rapid curation cumbersome.
   - WikiStub-Seed Solution: Human-readable JSON structure with built-in validation CLI (`wikistub_seed_cli.py check/stats`), duplicate verification, and optional local browser GUI (`python edit_server.py`).

3. Local-First & Zero-Egress Tool Builders
   - Needs: Build air-gapped, privacy-preserving desktop and offline mobile applications that provide instant reference and semantic search without internet connectivity.
   - Pain Points: SaaS dictionary and encyclopedia APIs leak user queries, demand API keys, and fail completely during travel or in secure network environments.
   - WikiStub-Seed Solution: 100% Local-First / Zero-Egress architecture (INV-LOCAL-01), zero telemetry, and a built-in Progressive Web App (PWA) with ServiceWorker caching and instant search.

4. Educators & Technical Documentation Specialists
   - Needs: Rapidly generate course glossaries, foundational concept notes, and study decks for students in Markdown, Obsidian vaults, or static web pages.
   - Pain Points: Manually writing multi-lingual definitions and linking related concepts across disciplines takes weeks of manual authoring.
   - WikiStub-Seed Solution: One-command batch export to categorized Markdown folders (`wikistub_seed_pipeline.py export --output --english`), easily imported into Obsidian, Docusaurus, or MkDocs.
