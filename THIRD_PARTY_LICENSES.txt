RUNTIME AND SOURCE SCOPE
The source checkout contains the CLI, editor, static PWA, dataset, and reusable Python
modules. The runtime wheel contains only:
  data_policy.py
  language_model.py
  safe_io.py
  translate.py
  wiki_auth.py
  wiki_store.py
The wheel does not contain the CLI, editor, dataset, or PWA. The local data/API modules
use the Python standard library.

OPTIONAL TRANSLATION
The translation command imports the anthropic SDK only when requested and configured.
The SDK is not an active requirements.txt dependency. Translation sends the requested
text and prompt to Anthropic and may incur charges. The local estimate/ceiling is not
a guarantee of the provider's bill.

DATA AND NETWORK BEHAVIOR
  Local validation, editing, import/export, and PWA builds operate on selected local files.
  The PWA service worker caches static app/data after a successful load; behavior depends
  on the browser and host.
  Translation is an explicit optional network operation. CLI use requires
  --confirm-api-cost and a positive --max-budget-usd. The estimate does not guarantee
  provider billing.
  The local edit server binds to 127.0.0.1; this is not a security certification.
